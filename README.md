# thai-trocr-finetuning

This repository contains code for finetuning the [TrOCR (Transformer-based Optical Character Recognition)](https://huggingface.co/docs/transformers/model_doc/trocr) model for Thai and English text recognition.

## Overview

TrOCR is an end-to-end text recognition model that uses a vision encoder and a text decoder to convert images of text into digital text. This repository contains the code we used to finetune the model specifically for Thai and English languages, improving its performance on these scripts.
